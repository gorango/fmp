# FMP Tools

Auto-generated [Vercel AI SDK](https://sdk.vercel.ai) tool definitions wrapping every `fmp-sdk` API function. Generated by `fmp-codegen`.

## Installation

```bash
npm install fmp-tools
```

Requires `fmp-sdk` as a peer dependency.

## Usage

```typescript
import { tools } from 'fmp-tools'
import { generateText } from 'ai'

const result = await generateText({
	model: openai('gpt-4o'),
	tools,
	prompt: 'What is the price of AAPL?',
})
```

Each tool wraps an SDK API function with a Zod input schema and an execute handler. Return values can be filtered to specific fields using the `values` parameter.

## Generation

To regenerate after SDK changes:

```bash
bun run --filter fmp-codegen generate:tools
```

## Exports

| Path | Description |
|---|---|
| `fmp-tools` | All tool definitions as a named export |
| `fmp-tools/docs` | Structured JSON documentation for every tool |
