# FMP Tools

Auto-generated [Vercel AI SDK](https://sdk.vercel.ai) tool definitions wrapping every `fmp-sdk` API function. Generated by `fmp-gen`.

## Installation

```bash
bun add fmp-tools
```

## Usage

```typescript
import { tools } from 'fmp-tools'
import { generateText } from 'ai'

const result = await generateText({
	model: openai('<model>'),
	tools,
	prompt: 'What is the price of AAPL?',
})
```

Each tool wraps an SDK API function with a Zod input schema and an execute handler. Return values can be filtered to specific fields using the `values` parameter.

## Generation

To regenerate after SDK changes:

```bash
bun run generate:tools
bun run generate:docs
```
